CHAD (CHoose A Date) Poll
Small web app where you can create a date poll, fill the poll and create a summary of votes.

Netlify Deployment
1. Place the contents of the folder into a GitHub repository and connect it to Netlify (Add new site -> Import from Git).
2. Go to Site configuration -> Environment variables and set: ADMIN_KEY = your long, secret password. Then, trigger a new deployment.
3. Open https://YOUR-SITE.netlify.app/ and log in using your password.
