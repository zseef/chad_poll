Időpontszavazó – Netlify telepítés
1. Tedd a mappa tartalmát egy GitHub tárolóba, és kösd össze a Netlify-jal (Add new site -> Import from Git).
2. Site configuration -> Environment variables: ADMIN_KEY = hosszú, titkos jelszavad. Utána indíts új deployt.
3. Nyisd meg: https://AZ-OLDALAD.netlify.app/  -> belépés a jelszóval.
